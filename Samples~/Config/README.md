# Config Sample

This sample provides one obvious place to configure DarkMagic:

- `VConfig.cs` – events, tracing, and example event types
- `SConfig.cs` – state-machine settings and example state types
- `WConfig.cs` – Awaitable tracing and guardrails
- `IConfig.cs` – custom input mappings
- `UConfig.cs` – code-first UI appearance and behavior
- `StatConfig.cs` – typed player/enemy StatBlock examples

## Import steps

Unity → Window → Package Manager → select **DarkMagic** → **Samples** → Import **Config**.
